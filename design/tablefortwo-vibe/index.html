Uncommitted exploration v2 · name stays, treatment changes

tablefortwo.

Keep the name, steal the startup grammar from the table. board: one word, lowercase, no spaces, tight tracking, one gold full-stop. “Table for Two” spelled out is a description; tablefortwo. is a brand — it reads like a domain, a handle, and an app icon label all at once, which is exactly how Linear / Notion / Arc feel modern. The “for two” stays front and centre: it’s the niche (intimate, hardest tables, date-night) that a bare “table” would have thrown away.

Rule zero: the name is written tablefortwo everywhere — nav, hero, icon label, footer, judges’ README. “Table for Two” only survives in prose on first mention (tablefortwo. (Table for Two)) and in SEO meta. The gold period means the same as before: done — considered seated.

1 · Wordmark directions — pick one

Recommended · A
tablefortwo.

A — tablefortwo. (one word + gold period)

  • Purest startup signal: lowercase single string, −0.055em tracking, the dot is the only ornament.
  • Matches the domain/handle reality: tablefortwo.city already reads this way — brand and URL finally agree.
  • Demo line: “This is tablefortwo. — it gets you in.”
Direction B
tablefortwo.

B — tablefortwo. (gold “two”)

  • Highlights the differentiator word; helps first-time readers parse the long string.
  • Risk: two-tone wordmarks age faster and complicate the favicon; use as a transitional lockup for one launch cycle, then graduate to A.
Direction C
tablefor2.

C — tablefor2. (numeral)

  • Shortest, most app-native; t42 energy you already use internally — great as the icon/handle shorthand.
  • Risk as master brand: numeral reads texting-casual, undercuts the luxury register. Keep for icon/social avatar, not the hero.
Direction D — status quo, refined
Table for Two.

D — TABLE FOR TWO. (letterspaced)

  • Today’s landing treatment with a period bolted on — hotel/fashion register, zero relearning.
  • Risk: still reads “restaurant guide,” not product. Included so you can feel the contrast and reject it on purpose.

My call: A as master, B as the one-cycle transition lockup (homepage hero + judges’ README header, so nobody misreads the string), C’s “2” lives only in the icon.

2 · App icon / favicon marks

Don’t discard the Muse Image icon you already shipped (candle-1) — it becomes the editorial art (hero, venue plates, share images), while the icon goes geometric. That split — clean mark, rich art — is the Linear/Arc pattern and it makes the halftone feel more premium, not less.
