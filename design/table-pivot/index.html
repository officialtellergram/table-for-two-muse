Pivoting to table.

The insight: “Let’s table this” already means save it for later in US English — and put it on the agenda in UK English. Both are literally the product: you table a restaurant now, we get you seated later. The verb becomes the brand, the saved list, and the button. Working line: We table tables.

The period is the asset. Lowercase table + a full-stop says done, handled, reserved — the way Linear/Notion/Arc use restraint as luxury. The dot can double as the candle, the plate, the “watching” pulse, and the app-icon mark. Keep the house palette (ink #0a0a0b, cream #f4f3f1, gold #c9a86a) and halftone art as texture behind a much cleaner wordmark — old-world restaurant, modern product.

1 · Wordmark directions — pick one

Recommended · A
table.

A — table. (lowercase + gold period)

  • Most startup-sleek: one word, tight −0.05em tracking, the gold dot is ownable at favicon size.
  • Reads as a sentence that’s finished: “Carbone, Saturday — table.”
  • Works spoken: “just table it.” Lockup: table. alone, never “Table.” capitalised.
Direction B
Table.

B — TABLE. (letterspaced luxury)

  • Closest to today’s landing wordmark; hotel / fashion-house register (Aman, Cartier).
  • Risk: reads more “restaurant group” than software product; weaker as a verb (“TABLE it!”).
Direction C
tabled

C — tabled. (past tense = done)

  • More ownable legally/domain-wise than bare “table”; the state your list is in.
  • Confirmation writes itself: “Tabled. We’re watching Carbone.”
  • Risk: one step removed from the idiom; “tabled” alone can sound like rejected in UK parliamentary use.
Direction D
let’s table.

D — let’s table. (phrase as brand)

  • The tagline is the name — maximally memorable in a 3-min demo (“Let’s table Carbone.”).
  • Risk: long for an icon/handle; better kept as tagline under A than as the master brand.

My call: A as master brand, D as tagline, C as the product noun — table. / let’s table this. / your Tabled list. All three reinforce each other instead of competing.

5 · Name architecture & tagline bank

Master + descriptor

  • table. — master brand (lowercase, gold period, always)
  • Descriptor for SEO/clarity at launch: “table. — hard-to-book restaurants, tabled for you”
  • Transition credit: “by the team behind Table for Two” for one cycle — don’t throw away the old name’s equity on day one
  • City lockups: table. NYC · table. DC …

Taglines (ranked)

  • Let’s table this. ← lead, it’s the idiom + the invitation
  • Consider it tabled.
  • We table tables.
  • Table now. Dine later.
  • Impossible tables, tabled.

⚠ Reality checks before committing

  • OpenTable is the elephant: “table” in restaurant reservations is crowded/descriptive — weak trademark, SEO fights a giant. tabled. is the more ownable fallback.
  • Domains/handles to check: table.com / gettable / tabled.app / @table — expect the bare word to be taken or premium; a hack (table.city, trytable) dilutes the sleekness.
  • US/UK split meaning is a feature in the pitch, a bug if a UK judge hears “shelved/rejected” — the demo line must land US-first.
  • For the 4 Nov submission: rename reads as polish, not new scope — safe this late only as wordmark + copy, not a rebuild.
